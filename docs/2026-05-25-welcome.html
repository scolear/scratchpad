Welcome to scratchpad

2026-05-25

This is a running collection of one-off HTML documents — reports, plans, summaries, option comparisons — published as a tiny static site so they can be shared with a link.

How it works

  • Each document is a self-contained HTML file in docs/
  • Filenames follow YYYY-MM-DD-short-slug.html so they sort naturally
  • The index lists every doc, newest first
  • Everything is published via GitHub Pages from scolear/scratchpad

Sharing a doc

Each doc has a stable URL of the form:

https://scolear.github.io/scratchpad/docs/<filename>.html

Paste that into Slack, email, anywhere. The doc is fully self-contained (inline CSS, no external assets), so links won't rot.
